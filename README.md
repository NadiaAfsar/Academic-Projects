# Academic & AI Projects

A collection of academic and personal projects in Data Structures, Algorithms, and Artificial Intelligences. Each project resides in its own directory with a dedicated README and source code.

## 📚 Projects

| # | Project | Domain | Language | Description |
|---|---------|--------|----------|-------------|
| 1 | [3D-rubik-s-cube-solver](3D-rubik-s-cube-solver/) | Artificial Intelligence | Python | A 3D Rubik's cube solver implementing 10 uninformed and informed search algorithms (BFS, DFS, UCS, A*, IDA*, RBFS, etc.) with a consistent heuristic. |
| 2 | [HybridAgent](HybridAgent/) | Artificial Intelligence | Python | A hybrid reasoning agent combining First-Order Logic (FOL) and Propositional Logic to decide room access based on organizational rules, blocking conditions, and working hours. |
| 3 | [Quoridor](Quoridor/) | Artificial Intelligence | Python | An AI agent for the board game Quoridor using Minimax with Alpha-Beta pruning, a custom heuristic based on shortest path distances, and full game rules. |
| 4 | [grapgh_analyzer](grapgh_analyzer/) | Data Structures | Java | A console application for managing directed weighted graphs with CRUD operations on vertices and edges, using HashMaps and sorted output. |
| 5 | [multi-robot-coin-collection](multi-robot-coin-collection/) | Algorithm Design | Java | A recursive backtracking algorithm to plan paths for multiple rectangular robots in a 3D grid to collect the maximum number of coins while avoiding collisions. |

## 🛠️ Technologies Used

- **Languages:** Java 17+, Python 3.8+
- **AI/ML:** Search algorithms, Minimax, Alpha-Beta, FOL, Propositional Logic
- **Data Structures:** Graphs, Trees, Linked Lists
